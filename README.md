# Lumina Bistro | Restaurant Website

A modern and responsive restaurant website designed to showcase the restaurant's brand, menu, culinary stories, and dining experience.

## Project Overview

Lumina Bistro is a restaurant website demo created using HTML5 and CSS3. The design focuses on an elegant visual identity, a clean layout, and a user-friendly browsing experience across desktop and mobile devices.

## Features

- Responsive navigation bar
- Homepage with a restaurant hero section
- About section introducing the restaurant
- Menu section for showcasing dishes
- Culinary blog and stories section
- Contact information and table-booking call to action
- Custom styling, typography, and hover effects
- Responsive layouts for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- Flexbox and CSS Media Queries
